# Portfolio Website by YP

## 🌟 Features  

- **💻 Responsive Design**  
  Fully optimized for desktop, tablet, and mobile devices.  

- **🌗 Dark/Light Theme Toggle**  
  Allows users to switch between themes for better usability.  

- **📜 Smooth Scroll Navigation**  
  Seamless navigation between sections with smooth transitions.  

- **🔍 Interactive Modals**  
  Portfolio items and service details open in dynamic, fullscreen modals.  

- **✨ ScrollReveal Animations**  
  Elements animate into view, adding a polished, modern touch.  

- **🖼️ Test Gallery Section**  
  A gallery to test and showcase creative layouts.  

- **⚡ Refactored for the future**  
  Prepared the project for future scalability and improvements by integrating Vite to ensure a modern development workflow.

  ---

## 🛠️ Tech Stack  

- **HTML5**  
  Semantic and accessible markup to ensure structure and compatibility.  

- **CSS3**  
  Advanced styling, including modern techniques like `backdrop-filter` for sleek visual effects.  

- **JavaScript (ES6)**  
  Adding dynamic interactivity and enhanced functionality. 

### 📚 Libraries Used  

- **Swiper.js**  
  Responsive, customizable sliders for better user engagement.  

- **ScrollReveal**  
  Smooth animations to enhance user experience.
